# nowfile

A personal status page that updates itself, readable over the finger protocol and the web.

```
$ finger mike@nowfile.org
```

Open source. Public server at nowfile.org; self-host with one binary. See `docs/brief.md` for what this is and `docs/format.md` for the document format.

To set your Status from a terminal, install `plan`: see [docs/install.md](docs/install.md). To set Focus from your iPhone or Mac Focus modes, see [docs/shortcuts.md](docs/shortcuts.md).
