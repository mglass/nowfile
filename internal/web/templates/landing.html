A status page that updates itself

nowfile is a short plain-text page saying what you are up to right now, in the spirit of the .plan file finger served in the 1990s and the away message. Every line carries an expiry, so stale lines disappear instead of lingering.

Read anyone's from a terminal:

$ finger mike@nowfile.org

Or in a browser at nowfile.org/mike, as plain text at /mike.txt, and as JSON at /mike.json. All three are the same document.

A document looks like this:

nowfile/0
Name: Mike Glass
Headline: Builds internal tools for small companies.
Link: https://glasseffect.com

Status: Lunch, back at 1
  set: 2026-10-13T16:04:10Z
  until: 2026-10-13T17:00:00Z
  source: web

Plan:
Reply within a day. Text for anything urgent.

You write the static part once and set a Status from the web, a shell one-liner, or anything that can make an HTTPS request with a token. The format is published, so a hand-written .plan on a classic finger server reads the same way.

Open source, free, no ads, no tracking.
